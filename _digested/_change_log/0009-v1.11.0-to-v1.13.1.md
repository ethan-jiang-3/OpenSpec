## 三个版本的核心主题

- **v1.12.0 — Findings 报告与规划落地**：`validate --report findings` 精简报告；新工具 SourceCraft（VS Code 扩展，tool id `codeassistant`）；propose/ff 变成 code-grounded（写 artifact 前先看代码、测试、文档）；explore 问依赖感知的问题、先查仓库再问用户。
- **v1.13.0 — archive/delta parser 正确性大修**：修了一批「写了但没生效、还报成功」级别的 bug（见下）。
- **v1.13.1 — 安全加固与工作流打磨**：敌意仓库输入加固；`status` 给 `Next:` 行；skills 只提 profile 内的 workflow；workflow 写文件前确认项目已 init；`/opsx:update` 先起草确认后写入；artifact 模板带顶层标题。
