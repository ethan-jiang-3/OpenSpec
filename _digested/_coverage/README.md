# _coverage — 源码消化覆盖矩阵

这个目录记录 `_digested/` 对源码的覆盖状态。它不是专题正文，而是维护用索引：帮助判断哪些源码子系统已经有机制级消化，哪些只是地图级提到，哪些还缺专题。

## 文件

| 文件 | 内容 |
|------|------|
| `src-coverage.md` | 按源码目录/模块追踪覆盖 |
| `specs-coverage.md` | 按 `openspec/specs/` 追踪覆盖 |
| `tests-coverage.md` | 按测试目录追踪覆盖 |

## 状态定义

| 状态 | 含义 |
|------|------|
| 机制级覆盖 | 有专题正文解释状态对象、关键算法/数据流、源码入口和边界 |
| 地图级覆盖 | 只在源码地图、命令矩阵或总览中出现 |
| 部分覆盖 | 有若干机制点被解释，但子系统仍缺完整专题 |
| 待补 | 基本没有进入 `_digested/` |
