# _spec_full_content — OpenSpec 应用指南

这个目录是对 `_digested/` 源码消化产物的**应用层输出**：按认知层次教你如何用好 OpenSpec，而不是剖析源码机制。

**与 `_digested/` 的关系**：`_digested/` 聚焦源码消化（机制剖析、架构解读），这里聚焦应用（怎么用、怎么落地）。两者互补 —— 想理解原理去 `_digested/`，想学会用就看这里。
