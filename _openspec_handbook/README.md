# OpenSpec 学习手册

> **手册版本 v1.0** · 对齐 openspec 1.4.1 · 2026-06。版本规则与变更记录见 [`00-index.md`](00-index.md) 的「版本与维护」。

按认知层次教你用好 OpenSpec：先会用，再懂概念，再看高级边界，最后进入实战和机器协议。自包含，独立可读。

术语上先记住一点：`openspec` 是终端 CLI 和文件状态机制，`/opsx:*` 是 OpenSpec 投递到 agent 工具里的命令入口。`opsx` 不是另一个产品，只是 slash command 命名空间。

## 阅读路径

- **只想先用起来** → 01 → 02
- **想真正理解 OpenSpec** → 01 → 02 → 03 → 04 → 05 → 06 → 09
- **想懂 specs 怎么组织、为什么会漂** → 02 → 09
- **多仓库场景** → 01 → 02 → 03 → 04 → 07
- **想看实际怎么落地** → 10 → 11 → 12 → 13 → 14 → 15
- **研究底层机制** → 读完主线后加 90

## 组织原则

编号按阅读难度和用途分段：

- `01-02`：基础概念
- `03-09`：高级思想和边界
- `10-15`：实战场景
- `90/99`：附录和 FAQ

这样排是为了让读者先建立 OpenSpec 的思想和边界，再看真实场景怎么用。
